# 🖼️ Image & PDF Processor

Простая и удобная программа на Python для **пакетной обработки изображений** и **сжатия PDF** файлов.

## Что умеет программа

- Конвертировать фото в разные форматы (PNG, JPEG, WebP)
- Сжимать и уменьшать размер изображений
- Автоматически поворачивать фото по EXIF (чтобы не было перевёрнутых)
- Показывать экономию места после обработки
- Сжимать PDF файлы
- Автоматически открывать папку с результатами
- Красивый интерфейс с прогресс-баром

## Возможности

- Выбор формата при конвертации
- Настройка максимального размера и качества
- Обработка всех файлов в папке одним запуском
- Отдельный режим сжатия PDF
- Подсчёт сэкономленного места
